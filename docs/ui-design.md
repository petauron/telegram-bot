# 群讯雷达界面重设计规范

本文档描述公开版管理界面的通用布局、组件和响应式约束，不依赖某个部署环境的截图或数据。

## 设计原则

1. 每个页面只有一个主任务；次级配置通过页内标签、抽屉或 disclosure 按需出现。
2. 列表、分隔线和开放式内容带优先于卡片网格；不嵌套无意义容器。
3. 第一层只显示结论和状态；诊断字段、完整模型响应和危险操作放在第二层。
4. 颜色只表达选择、健康和风险，不用装饰性渐变、发光或大面积语义色。

## Design tokens

- 页面背景：`#f6f8fb`；主表面：`#ffffff`；导航：`#071a34`。
- 主文字：`#10213d`；次文字：`#66738a`；弱文字：`#8a96aa`。
- 主动作：`#1267f4`；浅选中：`#eef5ff`；边框：`#d9e1ec`。
- 健康：`#11a85b`；警示：`#f08a00`；错误：`#dc3444`。
- 字体：系统中文无衬线；页面标题 28/34、区块标题 18/26、正文 14/22、控件 13/20、辅助 12/18。
- 桌面控件高 40px，移动触控目标至少 44px；圆角 10px（大表面）/ 7px（控件）。
- 阴影仅用于抽屉和登录面板；其余层级由边框、留白和背景区分。
- 动效 160ms，抽屉和选择行只动画 `opacity/transform/background-color`，支持 `prefers-reduced-motion`。

## 组件与容器

- `AppShell`：208px 桌面导航 + 64px 顶栏；移动端为 56px 顶栏 + 固定底部五项导航。
- `PageHeading`：标题、单句说明和最多一个主操作，不使用英文 eyebrow。
- `SignalStrip`：一条开放式关键数据带，不拆成多张统计卡。
- `NewsList`：分隔线列表、右对齐数字、钴蓝选择轨。
- `DetailDrawer`：桌面 430px 侧滑抽屉；移动端全屏/近全屏 sheet。
- `SectionTabs`：文字标签 + 2px 下划线；不用 pill。
- `FormSurface`：单一表面内用标题和分隔线组织字段；危险操作收进 disclosure。
- 图标沿用 Lucide outline，统一 18–20px、约 1.8px stroke；不增加装饰性图标。

## 页面信息层级与首屏文案锁

### 总览

- 标题：`资讯总览`
- 说明：`了解资讯采集、处理与推送的总体情况。`
- 关键数据：`今日采集`、`资讯合格`、`已推送`、`监听正常/离线`
- 主区：`值得关注`、`查看全部消息`
- 次区：`处理概况`、`服务状态`

### 消息流

- 标题：`消息流`
- 说明：`查看、筛选和审计已采集消息。`
- 首层筛选：搜索、群组、时间；最低分、推送和前置过滤进入 `更多筛选`。
- 首层列表：时间、消息与来源、AI 评分、推送状态。
- 详情标签：`概览`、`分析`、`原始响应`；原始响应默认不加载到视线层级。

### 规则配置

- 标题：`规则配置`
- 说明：`管理监听范围、资讯规则与模型分析。`
- 页内标签：`监听范围`、`资讯规则`、`模型分析`；一次只渲染一个配置域。

### 推送渠道

- 标题：`推送渠道`
- 说明：`选择资讯送达方式并验证连接。`
- 渠道标签：`Telegram Bot`、`ntfy`；一次只显示一个渠道表单。

### 运行状态

- 标题：`运行状态`
- 说明：`确认只读监听与数据采集是否正常。`
- 首层只显示连接结论、监控会话、最近心跳和安全边界；账号 ID 在技术详情中。

### 登录

- 品牌：`群讯雷达`
- 标题：`登录管理界面`
- 说明：`使用服务器配置的管理员账号登录。`
- 控件：`用户名`、`密码`、`登录`

## 响应式规则

- `<= 760px`：隐藏桌面侧栏，启用固定底部导航；主内容为单列。
- 消息列表在移动端只展示分数、两行消息、来源/时间和状态；选择后打开全屏详情。
- 表单标签允许横向滚动但不换成下拉；操作按钮在窄屏可占满宽度。
- 底部内容预留导航与 safe-area 空间，详情 sheet 打开时隐藏底部导航。
